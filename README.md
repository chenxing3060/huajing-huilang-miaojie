# 花境回廊 · 喵街微世界

> AI 原生互动玩法 — 银泰喵街会员促活与复购产品方案  
> OPC 3.0 全球超级个体商业挑战赛 · 银泰商业命题（赛题03）

## 项目简介

**花境回廊·喵街微世界** 是为银泰喵街 4500 万会员设计的 AI 原生互动养成玩法。用户以"回廊探员"身份领养 AIGC 专属晶灵，通过每日签到、做任务、到店消费获取源芯能量来喂养进化晶灵，在"打开 APP 养晶灵 → 社交分享炫耀 → 到店 AR 探索 → 回流复购"的循环中提升会员活跃度与复购率。

## 核心亮点

- 🎮 **AI 原生玩法**：AIGC 在晶灵生成、任务、对话、剧情、内容五大环节发挥不可替代作用
- 📱 **H5 交互原型**：37KB 单页应用，可直接运行体验核心玩法
- 🏪 **真实商业场景**：基于银泰百货 4500 万会员的促活与复购需求设计
- 🤝 **社交裂变**：晶灵进化一键分享、好友邀请碎片交换、PVE/PVP 组队

## 快速体验

打开 `prototype.html` 即可进入花境回廊：
1. 点击「进入花境」领养你的晶灵
2. 每日签到获取能量
3. 完成 AI 任务喂养晶灵
4. 集满能量触发进化
5. 分享你的晶灵到社交平台
